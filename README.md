# Daily planner

Hourly day view, weekly repeats, automatic habit logging. Live at https://pranavmaheshwari06.github.io/Daily-planner/
(sign in with Google; data syncs through Firebase). See `docs/PLAN.md` and `docs/PLAN-v4.md`.

    npm install
    npm test        # logic tests + build + smoke test + Sheets export test
    npm run build   # dist/index.html (the site), dist/planner.html, dist/logic.js

Push to `main` to deploy.
